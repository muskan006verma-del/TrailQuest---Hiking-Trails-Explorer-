🌲 About TrailQuest

TrailQuest is a Hiking Trails Explorer created as a Python mini project to help users discover hiking destinations, compare difficulty levels and explore important trail information through a simple and attractive website.

Features

  • Browse a directory of hiking trails
  • Search by trail name or location
  • Filter trails by Easy, Moderate or Hard
  • View distance, duration, elevation and best time to visit

Technology

Python Flask backend, HTML and CSS frontend, built in VS Code. This preview runs fully in the browser so you can try how the website works.
